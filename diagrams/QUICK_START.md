# Quick Start - Creating Diagrams

## 🚀 Fastest Way (2 minutes)

### Step 1: Go to MermaidChart.com
Open: https://mermaidchart.com

### Step 2: Sign In
- Click **"Sign In"**
- Use Google/GitHub/Email (free account)

### Step 3: Import Diagram
1. Click **"New Diagram"**
2. Click **"Import"** button
3. Select any `.mmd` file from this folder
4. Diagram appears instantly!

### Step 4: Export
1. Click **"Export"** button
2. Choose **PNG** or **SVG**
3. Download and use!

## 🎨 Quick Customization

### Change Diagram Title
In MermaidChart.com:
1. Click diagram title at top
2. Type new name
3. Press Enter

### Change Colors
Find this line in code:
```
style ComponentName fill:#326CE5
```

Change the color code:
- Blue: `#0078D4`
- Green: `#107C10`
- Red: `#D13438`
- Purple: `#5B5FC7`
- Orange: `#FF8C00`

### Change Text
Just click on any text in the visual editor and type!

## 💾 Recommended Export Settings

### For PowerPoint:
- Format: **PNG**
- Size: **1920 x 1080**
- DPI: **300**

### For Word/PDF:
- Format: **SVG** (scalable)
- Or PNG at **300 DPI**

### For Web/Confluence:
- Format: **SVG** (best quality)
- Or PNG at **150 DPI**

---

## 🔄 Updating Diagrams

### If You Change Code:
1. Open `.mmd` file in VS Code
2. Make changes
3. Copy all content
4. Paste in MermaidChart.com
5. Export new version

### If You Edit Visually:
1. Edit in MermaidChart.com
2. Click **"Code"** tab
3. Copy code
4. Paste back into `.mmd` file
5. Save

## 🆘 Common Issues

### "Diagram won't load"
- Check file is `.mmd` format
- Try copy-paste instead of import

### "Colors look different"
- MermaidChart.com may use different theme
- Adjust in visual editor

### "Text is cut off"
- Increase canvas size in export settings
- Or use shorter text
